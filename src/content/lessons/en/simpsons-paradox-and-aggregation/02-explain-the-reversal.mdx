Routine: $9/10-72/90=9/10-4/5=1/10$. Complex: $36/90-3/10=2/5-3/10=1/10$. A has the higher success proportion within each named stratum. The **overall ranking** compares different sets of records: A’s full workload against B’s full workload.

A strict Simpson reversal in this course means one option is higher inside every supplied stratum but lower when each option’s own records are pooled. Other changes in magnitude, a single reversed stratum or a crossing conditional ordering are different patterns; not every surprising percentage is this strict reversal.

Thus A minus B is $45/100-75/100=-3/10$, or minus thirty percentage points. Most A attempts are in the lower-success complex group. Most B attempts are in the higher-success routine group. This accounting locates the composition term; it does not tell us why allocation happened or identify an effect of changing the route.

### When to inspect composition

Do it before presenting the pooled ranking as if it were a matched-group comparison. A different workload can matter without proving intentional cherry-picking, incompetence or any other story about the people allocating the work.

## Find the boundary for hypothetical mixtures

Hold the four conditional fractions fixed and consider alternative routine shares $w_A,w_B\in[0,1]$. These are stipulated mixture inputs, not a claim that old records change when we move a control.

$$R_A=\frac25+\frac12w_A,\qquad R_B=\frac3{10}+\frac12w_B.$$

Subtracting gives

$$R_A-R_B=\frac1{10}+\frac12(w_A-w_B).$$

B’s mixture is higher exactly when $w_B-w_A>1/5$. At equality the mixtures tie. If $w_A=2/5$ and $w_B=1/2$, the weights differ, yet A is $3/5$ and B $11/20$: A still leads by $1/20$. Unequal composition is necessary for this particular common-direction reversal, but it is not sufficient.

## Apply the same weights and check what survives

Now give both options one declared reference, half routine and half complex. This is a different calculated comparison: A becomes $13/20=65\%$ and B $11/20=55\%$. The original count table remains unchanged.

More generally, with common nonnegative weights $v_g$ summing to one, the index difference is $\sum_g v_g(r_{Ag}-r_{Bg})$. If every positive-weight stratum has a strictly positive difference, this sum is strictly positive. If some differences are merely zero, the conclusion may be a tie; a positive difference given zero weight contributes nothing. Required proportions must be defined where the reference weight is positive.

In the MAIN case both differences are $1/10$, so every supported common reference preserves that exact advantage. This statement concerns a shared-weight index. It does not say that one route caused an improvement or that its observed overall result was miscalculated.
