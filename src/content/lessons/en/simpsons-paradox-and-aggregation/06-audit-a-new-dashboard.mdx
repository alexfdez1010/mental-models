A restoration workshop compares two inspection routes. A sheet either passes the specified checks in the fixed completed audit window or does not. Each sheet has exactly one recorded inspection and outcome. Flat and fold-out classifications are known before route allocation, cover all sheets and do not overlap. The fictional record set is complete; allocation is not stated to be random.

This is a fresh problem. The counts differ from the export case, and the routes do not have the same conditional advantage in both strata. Use the inputs before opening the worked solution.

## Inspect the complete solution

<summary>Open the transfer calculation</summary>

C’s observed fraction is $(15+18)/(20+60)=33/80=41.25\%$. D’s is $(42+4)/(60+20)=46/80=23/40=57.5\%$. The observed C-minus-D difference is $-13/80$, or minus 16.25 percentage points.

Within flat sheets, C is $15/20=3/4$, D $42/60=7/10$ and the difference $1/20$. Within fold-out sheets, C is $18/60=3/10$, D $4/20=1/5$ and the difference $1/10$. C is higher in both, yet its own pooled result is lower because the observed group compositions differ.

## Change the reference without changing the records

Let $w$ be a common flat-sheet share. The conditional differences give

$$I_C-I_D=w\frac1{20}+(1-w)\frac1{10}=\frac1{10}-\frac{w}{20}.$$

For $w\in[0,1]$, the gap ranges from $1/10$ to $1/20$ and stays positive. The equal reference gives the midpoint $3/40$. This differs from MAIN: both retain the same sign under a common reference, but only MAIN keeps exactly the same gap at every shared weight. The reference can change the magnitude without changing the ranking.

Both options have recorded support in each stratum here. If an otherwise required cell were absent, this reference formula would need a missing-input check before a point index. More data from a different inspection definition would not automatically solve that compatibility problem.

### When to make a recommendation

First decide whether the recommendation concerns these records, a reference index, a future workload or an intervention. This constructed audit supports the first two calculations. A real future or causal recommendation needs the additional evidence its question requires.

## Write an auditable conclusion

A defensible report can say: “D’s recorded success proportion is higher in its own audited workload. C’s proportion is higher within each sheet type, and C has the higher index under the declared equal-type reference.” It should give the counts and reference, rather than hiding either result.

That report still does not say that switching every sheet to C would cause the calculated gain. The possible-world exercise showed why a table alone does not identify that effect. Nor does the current complete window establish stable future conditional rates.
