A common reference holds composition fixed so that a comparison answers one declared question. It does not discover which population you ought to care about. That choice belongs to the decision, and it should be stated before looking for a flattering result.

## Define the reference before calculating

A **reference population** here means a declared group composition used for weighting. It may be represented by weighting units such as one routine and one complex unit. Those units are not additional observed documents. A **standardized index** applies that composition to each option’s within-group fractions.

For the MAIN counts, a half-routine/half-complex reference gives:

$$I_A=\frac12\frac9{10}+\frac12\frac25=\frac{13}{20},\qquad I_B=\frac12\frac45+\frac12\frac3{10}=\frac{11}{20}.$$

A’s contributions are forty-five and twenty percentage points; B’s are forty and fifteen. The calculation holds the mix fixed, rather than replacing A’s actual routine denominator with B’s or manufacturing new successes.

### When to use direct standardization

Use it for a question that compares group-specific performance under one stated composition. The [NCHS definition of direct adjustment](https://www.cdc.gov/nchs/hus/sources-definitions/age-adjustment.htm) uses the same weighting operation and distinguishes a comparative index from an actual individual risk. This course applies that accounting to constructed nonclinical proportions, without importing a medical conclusion.

X is stronger in routine records and weaker in special records. Let $w$ be the common routine reference share. Then

$$I_X=\frac1{10}+\frac45w,\qquad I_Y=\frac25+\frac15w,\qquad I_X-I_Y=\frac35w-\frac3{10}.$$

At a quarter routine, X is $3/10$ and Y $9/20$. At three quarters routine, X is $7/10$ and Y $11/20$. At half routine they tie exactly at $1/2$. A target-dependent index ranking is possible because the conditional ordering crosses; it is not the MAIN case’s strict within-all/overall reversal.

## Keep the target defensible and the support visible

An index is interpretable only with compatible outcome definitions, units, strata and a named reference. It also needs a defined within-stratum fraction for every positive reference weight. A zero-weight group contributes nothing, but a positive-weight missing fraction is not filled by calling it zero. The support lesson will work that failure explicitly.

The common reference can reflect a specified workload, a comparison standard or another declared target. This table alone cannot choose a uniquely fair standard. If a manager chooses the routine share only after discovering which option it favours, the arithmetic may be correct while the answer no longer addresses the original question.

### When a ranking is robust to the reference

If all used group differences have the same strict sign, their common weighted sum has that sign. If signs cross, test the actual permitted references or derive a boundary. Do not infer robustness from one convenient preset or infer a reversal from different weights alone.

## Separate an index from a forecast

The current table describes one complete window. Applying its fractions to a future workload would assume that the relevant performance relationships transfer. That may fail if document definitions, validation rules, assignment processes or unmeasured case characteristics change. Sampling uncertainty would also matter if the fractions were estimates from samples; this exact fictional census does not measure uncertainty away for future work.

A common-reference calculation is therefore a useful comparison with a stated target. It does not promise that assigning every new item to the higher-index option will cause the index value to occur.
