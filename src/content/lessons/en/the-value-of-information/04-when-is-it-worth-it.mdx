You are 95% sure a workshop jig will suit a job. Is checking it a waste of time? That percentage cannot price the check. We still need to know what happens if the jig is unsuitable, what the check can reveal and which choices remain available.

Earlier lessons defined the **expected value of perfect information (EVPI)** and the **expected value of sample information (EVSI)**. This lesson builds a reliable rule for when to investigate: compare complete decision policies against the best policy already available, then deduct the additional costs. Confidence alone is not a stop rule.

## Start with the best decision you can already make

Consider a **hypothetical one-project decision**. A team can use a jig, a device that holds pieces in position, or keep its standard method. The uncertain state is whether the jig is suitable for this job. All values are **net staff-minutes saved relative to the standard method**:

| Action | Suitable jig | Unsuitable jig |
|---|---|---|
| Use the jig | +400 | −300, meaning 300 minutes of extra work |
| Use the standard method | 0 | 0 |

These are stated assumptions, not workshop performance data. Both methods meet the same quality requirements. The objective is expected total staff time, with no separate safety, deadline or maximum-loss constraint overriding it. The state stays fixed, a report arrives before the method choice and obtaining it does not itself improve the jig. The table excludes test effort, which we will deduct separately once.

Let **p** be the prior probability of suitability. Using the jig has expected savings **400p − 300(1 − p) = 700p − 300**. The standard method gives zero. The **best no-test value**, called **V₀**, is therefore:

**V₀ = max(0, 700p − 300)**

Use the jig when **p > 300/700 = 3/7 ≈ 42.86%**. At the threshold the methods tie; our convention is to keep the standard method. A threshold is a boundary between actions, not a universal percentage of sufficient confidence.

For the initial **p = 40%**, the jig's expected saving is **0.40 × 400 − 0.60 × 300 = −20 minutes**. Keep the standard method, so **V₀ = 0**. At **p = 90%**, use the jig: **0.90 × 400 − 0.10 × 300 = 330**, giving **V₀ = 330**. Information must earn an improvement over that existing 330, not receive credit for the whole tested policy payoff.

This comparison of the expected best action after evidence with the current best action is the decision-analysis construction set out in [Berkeley's decision-network text](https://inst.eecs.berkeley.edu/~cs188/textbook/vpis/vpi.html). [Howard's original information-value paper](https://doi.org/10.1109/TSSC.1966.300074) likewise distinguishes the probabilities of messages from the consequences that make those messages useful to a decision-maker.

## Locate the peak from the payoffs, not the amount of uncertainty

<MCQ

With perfect information, use the jig only when suitable. Its policy value is **400p**. Subtract the best no-test value:

**EVPI = 400p − max(0, 700p − 300)**

Below the threshold, no-test uses the standard method. Perfect information gains the suitable-job opportunities, so **EVPI = 400p**. Above the threshold, no-test uses the jig. Perfect information avoids the unsuitable-job losses, so **EVPI = 300(1 − p)**.

| Prior p | Best no-test value | Perfect-policy value | EVPI, all in staff-minutes |
|---|---|---|---|
| 0% | 0 | 0 | 0 |
| 40% | 0 | 160 | 160 |
| 3/7, about 42.86% | 0 | 1200/7 | 1200/7 ≈ 171.43 |
| 50% | 50 | 200 | 150 |
| 90% | 330 | 360 | 30 |
| 95% | 365 | 380 | 15 |
| 100% | 400 | 400 | 0 |

In the bounded model with gain **G > 0**, loss **L > 0** and the same zero-valued alternative:

**Action threshold = L/(G + L)**

**EVPI = min(pG, (1 − p)L)**

For fixed payoffs, its peak is at **p = L/(G + L)** and has value **GL/(G + L)**. Here that is **1200/7 minutes**, at a prior of **3/7**. An even split gives only 150. If gain and loss are equal, the threshold and peak are at one half; that special case does not supply a rule for all decisions.

At the prior extremes, EVPI is zero **in this model** because the relevant state is already known. At 95% it is 15, not zero. Whether a check is worthwhile depends on what it can achieve and what it costs.

### A large expected lead is different from dominance

At a 90% prior, the jig beats the standard method by 330 **in expectation**. It still loses 300 in the unsuitable state. A perfect report avoids that statewise loss, yielding **360 − 330 = 30** extra expected minutes. A large prior lead does not rule out a valuable signal.

By contrast, suppose a different jig saves **400 if suitable and 50 even if unsuitable**, while the standard method still saves zero in both states. The jig is then better **in every state with positive probability**. This is statewise dominance. The same action is best before and after any report, so EVPI is zero for that decision even if the state remains uncertain. Do not apply the earlier positive-loss formula to this changed payoff table.

<Callout variant="tip" title="The useful zero test">
If one available action remains optimal for every possible result, the report adds zero gross decision value under the model. A lopsided prior, a small payoff or a large expected lead does not establish that condition by itself.
</Callout>

## Price the noisy policy, including the errors it still makes

Return to the original **400 / −300** payoff table and **40%** prior. A report gives a favourable signal in **80% of suitable jobs**, and an unfavourable signal in **80% of unsuitable jobs**. These are two conditional performance rates, assumed equal here. A single overall accuracy number would not specify a general asymmetric test.

The following expected-frequency table uses 100 probability-weighted jobs for bookkeeping. It is not an observed sample or a promise about the next 100 jobs:

| Report result | Suitable, prior weight 40 | Unsuitable, prior weight 60 | Total weight |
|---|---|---|---|
| Favourable | 40 × 0.80 = 32 | 60 × 0.20 = 12 | 44 |
| Unfavourable | 40 × 0.20 = 8 | 60 × 0.80 = 48 | 56 |

After favourable news, suitability has probability **32/44 = 8/11 ≈ 72.73%**: use the jig. After unfavourable news, it has probability **8/56 = 1/7 ≈ 14.29%**: use the standard method. Both choices follow the **3/7** threshold.

The favourable branch contributes **0.32 × 400 − 0.12 × 300 = 92 minutes**. The unfavourable branch contributes zero. Hence:

- **Gross test-policy value = 92**.
- **EVSI = 92 − V₀ = 92 − 0 = 92**.
- With total test effort **20**, **incremental net = 92 − 20 = 72 minutes**.

The test does **not** keep every good outcome and discard every bad one. There is still joint probability **0.12** of using an unsuitable jig, and probability **0.08** of declining a suitable one. Compared with perfect information, those errors lose **0.12 × 300 = 36** and **0.08 × 400 = 32** expected minutes. The gap is **36 + 32 = 68 = 160 − 92**.

## A high prior can leave a valuable decision unresolved

Change the job's payoff table: a suitable jig saves **100 minutes**, but an unsuitable one creates **1900 minutes of extra work**. The standard method still gives zero. The prior is **95% suitable**, and the actions remain feasible under our expected-time objective.

The threshold is **1900/(100 + 1900) = 95%**. The no-test values tie:

**0.95 × 100 − 0.05 × 1900 = 95 − 95 = 0**

Perfect information gives **0.95 × 100 = 95 minutes** and therefore **EVPI = 95**. High confidence in the favourable state has not eliminated decision uncertainty: the uncommon loss is large enough to matter.

For a report with **90%** correct signals in each state, favourable news has probability **0.95 × 0.90 + 0.05 × 0.10 = 0.86**. The suitability posterior is **0.855/0.86 = 171/172 ≈ 99.42%**, so use the jig. After unfavourable news it is **0.095/0.14 = 19/28 ≈ 67.86%**, so keep the standard method.

Gross policy value is **0.855 × 100 − 0.005 × 1900 = 85.5 − 9.5 = 76 minutes**. EVSI is **76 − 0 = 76**. With **16 minutes** of total test effort, incremental net is **60**. No universal “95% sure, stop researching” cutoff survives this example.

## Use weak bounds and deduct costs in consistent units

Under the assumptions above, **0 ≤ EVSI ≤ EVPI**. These are **weak inequalities**: equality is allowed.

The lower bound follows because you may ignore a result and keep the best no-test action. The upper bound follows because no report-guided action can outperform the best action for the true state when that state is known. The comparison keeps the same actions, payoff table and decision horizon. If testing changes the process itself, supplies new actions or creates other benefits, model those changes rather than assigning them silently to information.

More generally, for finite sets of states **θ**, feasible actions **a** and report results **S**, with payoffs **u(a, θ)**:

- **V₀ = max over a of E[u(a, θ)]**.
- **Vₛ = E over S of [max over a of E[u(a, θ) given S]]**.
- **Vₚ = E over θ of [max over a of u(a, θ)]**.
- **EVSI = Vₛ − V₀**, and **EVPI = Vₚ − V₀**.

Choose after each possible result, then average **before** observing which result arrives. Reversing the maximum and expectation changes the question. [Purdue's engineering decision-analysis module](https://engineering.purdue.edu/DELP/education/decision_making_slides/Module_09___Value_of_Information.pdf) works through this result-by-result construction for an imperfect sensor.

### Equality and action changes

The original table with a **100%** reliable report has **EVSI = EVPI**, not a strict gap. The changed, statewise-dominant jig has **EVSI = EVPI = 0**. Equality with perfect information can also occur without revealing every detail: a report might identify suitability perfectly while leaving the exact material grade unknown, when that grade does not change either action's payoff. It then reveals everything needed for the optimal action, though not the full state description.

For a specified report, gross EVSI is zero if an action optimal without the report remains optimal after **every positive-probability result**. Switching between tied actions does not create a strict benefit. Under this finite expected-payoff model, positive EVSI requires some result of positive probability to make a different action **strictly better** than the chosen no-test action.

A useful way to audit the gain is to sum, over results, **result probability × conditional improvement over the original action**. Each term is nonnegative when the result is used optimally. A short slogan such as “chance of a flip times its value” works only if “value” means that conditional expected improvement, averaged appropriately; counting all action changes or all reduced uncertainty is insufficient.

### Scaling is exact for gross value, conditional on what is scaled

Multiply **every action-state payoff** by the same positive factor, holding probabilities and available actions fixed. Optimal actions stay the same, and gross EVPI and EVSI multiply by that factor exactly. Net value scales only if costs scale too.

| Original-table variant, still at the same prior and test performance | EVPI | EVSI | Test effort | Incremental net |
|---|---|---|---|---|
| +400 / −300 minutes | 160 | 92 | 20 | 72 |
| Payoffs divided by 1000: +0.4 / −0.3 minutes, effort unchanged | 0.16 | 0.092 | 20 | −19.908 |
| Both payoffs and effort divided by 1000 | 0.16 | 0.092 | 0.02 | 0.072 |

All entries remain **minutes**, not currency or a different unit inferred from their size. For example, **0.16 minutes = 9.6 seconds**. The lab cannot enter these tiny payoffs because its gain/loss controls start at ten; use the table's exact arithmetic. Small positive information value remains positive, even when obtaining it is not worthwhile.

Compare **incremental net = EVSI − total additional cost** with zero. A positive value beats no test within the stated alternatives; zero is a tie, not a strict reason to buy. A negative value loses to no test. Include effort, interpretation and relevant delay or implementation costs once, in the same payoff units. The ceiling is a screening tool: if every feasible test costs more than EVPI, none can repay those costs through this decision's information benefit alone.

## Keep the remaining choices in view

Learning before committing can preserve flexibility: you may condition a later action on a result. That resembles an option, but a noisy report does not grant a right to keep every good outcome and eliminate every bad one. Our table showed both false favourable and false unfavourable outcomes, and the possible benefit is bounded by the specified payoffs.

After a commitment, ask which **remaining decisions** can still change. Preparation, mitigation, scheduling or future jobs may remain open. If the report affects none of the actions or payoffs in the stated horizon, its decision value is zero for that horizon. If another decision remains, value that decision with its current actions and incremental costs. Sunk commitments do not establish that all future information is worthless.

### Transfer to a different setup decision

For a separate room-setup job, an alternative layout saves **90 minutes** if suitable and adds **10 minutes** if unsuitable. The standard layout gives zero. Suitability has prior probability **80%**. A perfect check uses **3 minutes**, and there are no other effects or constraints.

A practical review therefore asks: **What can I still choose? Which possible result would improve that choice? How much does the complete policy improve over the best no-test policy? Does that improvement cover the additional costs under plausible inputs?** A useful answer names the action, threshold, probabilities and units. “I'm already quite sure” does not do that work.
