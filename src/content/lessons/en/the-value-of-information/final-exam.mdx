This is the final exam for **The Value of Information**. It covers the action-change screen, perfect and imperfect information, Bayesian updating, research costs, competing protocols and the next-experiment stopping rule. Compare the best policy with the information against the best policy already available. Where a question gives numbers, compute the comparison.

<Callout variant="warning" title="How this exam works">
Each question appears one at a time. Submitting locks that answer for this run, with no back button, retry or restart. The total score appears only after the last question. **The pass mark is 70%.** Some questions ask you to select all correct answers.
</Callout>

Unless a question says otherwise, gross information value assumes the same feasible actions and outcome model, a result available before the relevant decision, and freedom to ignore the signal. Test effort and any additional timing effects are deducted separately and once. A probability estimate, an expected-value lead or a confidence percentage alone does not establish whether a particular study can change the optimal action.

### Archive sorting case

The following **hypothetical** case supports the applied calculation questions. An archive can switch sorting methods or keep its current method. Quality is unchanged, both actions are feasible and the objective is expected staff-minutes saved. All test effort is separate from the production payoffs.

| Input | Value |
|---|---|
| Switching with suitable material | +150 minutes |
| Switching with unsuitable material | −50 minutes |
| Keeping the current method in either state | 0 |
| Prior probability of suitability | 40% |
| Favourable signal given suitability | 80% |
| Unfavourable signal given unsuitability | 80% |
| Complete test effort | 7 minutes |

The policy using the signal switches after favourable news and keeps the current method after unfavourable news. The result arrives before the decision, without other effects.

<Callout variant="success" title="Key takeaways">
Gross information value measures the expected improvement of the best policy using a signal over the best policy already available. Its non-negativity assumes the original policy remains available and the signal can be ignored. EVPI bounds that improvement under the same model; EVSI prices the stated imperfect signal. Compare incremental net values after counting each additional cost once. Derive action thresholds from the payoffs, validate relevant test likelihoods and update from evidence already observed. Stop before a proposed experiment whose possible results cannot improve the action, while checking separately any stronger or joint information policies that are actually available.
</Callout>
