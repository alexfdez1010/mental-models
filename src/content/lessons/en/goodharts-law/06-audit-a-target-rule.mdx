Every submission passes the format score. The exhibition organiser celebrates. Half the submitted puzzles still have no valid solution.

A higher score could reflect better puzzles, cosmetic changes or a different incoming population. To audit the rule, you need to distinguish those possibilities and calculate what the rule makes worthwhile. This workshop uses a complete, invented model. Its probabilities, editing costs and utility units are teaching inputs, not measured behaviour.

## Write down the decision and what can change

A **classifier** assigns a category to an input. Our organiser uses a format score to accept or reject a puzzle. Genuine validity **G** is 1 when the puzzle has a valid solution and 0 otherwise. The objective is **classification accuracy**: the probability of making the correct accept/reject decision.

Accepting an invalid puzzle is a **false positive** (FP). Rejecting a valid puzzle is a **false negative** (FN). Both errors have equal weight. Acceptance volume, participant effort, fairness and the exhibition's wider value are separate objectives, not silently included in accuracy.

The initial population has four equally probable types:

| Type | Genuine validity G | Original score x | Probability |
|---|---|---|---|
| A | 0 | 0 | 1/4 |
| B | 0 | 1 | 1/4 |
| C | 1 | 2 | 1/4 |
| D | 1 | 3 | 1/4 |

This is a probability catalogue, not a prediction that four random arrivals contain one of each type. We use four equally weighted **type slots** to calculate probabilities exactly.

The organiser observes only the **final score**, not the arriving submission's original type, original score or G. The table is the learner's complete audit model. Knowing the population law does not identify which hidden type produced one final score.

The organiser commits to one of six public cutoff rules. Accept when the final score is **at least the cutoff**.

| Rule | Cutoff |
|---|---|
| Open | 0 |
| Low | 1 |
| Original | 2 |
| Raised | 3 |
| High | 4 |
| Top | 5 |

After seeing the rule, a participant can make **e = 0, 1, 2, 3 or 4** cosmetic edits. Final score is **x + e**, with no clamp: it can reach 7. Edits never change G. Genuine improvement is excluded from this small action menu to isolate proxy manipulation; real authors may have other options.

Acceptance is worth **2.5 private utility units** to each participant; rejection is worth zero. An edit costs **k utility units**. Participants maximise:

**Utility = 2.5 × accepted − k × e**

Accepted is 1 for acceptance and 0 for rejection. No editing always costs zero. The benefit is a value to the participant, not an extra invoice in the organiser's objective. Start with **k = 1**. No other motive, future reward, collusion or alteration of G enters this one-shot game.

### When to use this setup

Define observations, actions, costs and benefits before predicting gaming. [Hardt and colleagues' strategic-classification model](https://arxiv.org/pdf/1506.06980), section 1.1, separates the rule, the response and classification against the original state. Our parameters are a local construction.

## Solve the response before judging the score

<MCQ client:visible pretest
  question="A participant already clears the cutoff. What does another cosmetic edit do under this utility rule?"
  options={[
    { text: 'It adds cost without increasing the acceptance benefit.', correct: true },
    { text: 'It increases the benefit in proportion to the score.' },
    { text: 'It improves genuine validity whenever the score rises.' }
  ]}
  explanation="Acceptance has the same benefit at every qualifying score. An extra edit consumes utility without changing G. The participant has no reason to overshoot."
/>

A **best response** maximises utility after the organiser commits to its rule. Work through type B under Original: x = 1, cutoff = 2, k = 1.

| Edits e | Final score x + e | Accepted | Editing cost | Net utility |
|---|---|---|---|---|
| 0 | 1 | No | 0 | 0 |
| 1 | 2 | Yes | 1 | 2.5 − 1 = 1.5 |
| 2 | 3 | Yes | 2 | 2.5 − 2 = 0.5 |
| 3 | 4 | Yes | 3 | 2.5 − 3 = −0.5 |
| 4 | 5 | Yes | 4 | 2.5 − 4 = −1.5 |

One edit uniquely wins. It changes acceptance while the puzzle remains invalid. Here **gaming** means strategic input modification without the corresponding genuine improvement. It need not involve dishonesty: cosmetic edits are permitted.

Repeat the comparison for every type under Original:

| Type | Best edit e | Final score | Accepted | Correct classification |
|---|---|---|---|---|
| A | 2 | 2 | Yes | No |
| B | 1 | 2 | Yes | No |
| C | 0 | 2 | Yes | Yes |
| D | 0 | 3 | Yes | Yes |

Before edits were available, Original rejected A/B and accepted C/D: **4/4 correct**. After responses it accepts **4/4**, but only **2/4** decisions are correct. There are two false positives and no false negatives. G has not declined; it remains **[0, 0, 1, 1]**. Classification using the final score deteriorated.

Edits beyond the cheapest crossing are **dominated**: they cost more for the same benefit. If crossing costs more than 2.5, staying wins. These comparisons simplify the enumeration without removing an action. A half-integer benefit and integer costs make every main/transfer best response unique. With exact equality, a tie convention would need to be stated, not silently assumed.

## Compare every permitted cutoff on the actual objective

<MCQ client:visible pretest
  question="Original now accepts every type. What should the organiser compare next?"

    { text: 'Accuracy after responses under every permitted rule.', correct: true },
    { text: 'Cutoff size, selecting the largest because tighter must be better.' }

Each rule creates a new response problem. Under High, cutoff 4, A needs four edits and B three. Their costs exceed the benefit, so both stay and are correctly rejected. C needs two edits, with net utility **2.5 − 2 = 0.5**; D needs one, with net utility **1.5**. Both are correctly accepted.

The complete menu at k = 1 follows. Edit vectors give **A; B; C; D** in order. Accepted and Correct count equal-weight type slots. FP/FN are error counts; Mean cost is the population-weighted private editing cost.

| Rule | Cutoff | Edits A; B; C; D | Accepted | Correct | FP; FN | Mean cost |
|---|---|---|---|---|---|---|
| Open | 0 | 0; 0; 0; 0 | 4 | 2 | 2; 0 | 0 |
| Low | 1 | 1; 0; 0; 0 | 4 | 2 | 2; 0 | 1/4 |
| Original | 2 | 2; 1; 0; 0 | 4 | 2 | 2; 0 | 3/4 |
| Raised | 3 | 0; 2; 1; 0 | 3 | 3 | 1; 0 | 3/4 |
| High | 4 | 0; 0; 2; 1 | 2 | 4 | 0; 0 | 3/4 |
| Top | 5 | 0; 0; 0; 2 | 1 | 3 | 0; 1 | 1/2 |

High uniquely maximises accuracy in the menu: **4/4 = 100%**. Top falls to **3/4 = 75%**. It does not reject everyone: D can reach score 5 with two edits. No score was clamped to the original range.

These are exact model probabilities, not trial estimates. A rule that looked poor before adaptation can perform well after its induced responses. Raised has unchanged accuracy, but its error switches from a false negative before edits to a false positive afterwards. Equal accuracy does not preserve every consequence.

High also imposes costs. Across A/B/C/D they are **0, 0, 2 and 1**, totalling **3** over the catalogue. The population mean is **(0 + 0 + 2 + 1)/4 = 3/4 utility unit**. Three is the sum, not the cost per arrival. Giving that burden weight, or weighting FP/FN differently, would change the objective and require another comparison.

### When to use the comparison

Use it before replacing a weak target with a stricter one. Solve responses, evaluate the actual objective and inspect side effects. This proves a best rule among six under known types and costs, not a real screening system's effectiveness or optimality among every possible decision procedure.

## Diagnose what identical scores cannot tell you

<MCQ client:visible pretest
  question="A later population has the same final-score distribution as the strategic population. Does that establish that participants edited their scores?"
  options={[
    { text: 'Yes, because identical scores must have identical causes.' },
    { text: 'No, because a changed intake can produce the same scores.', correct: true },
    { text: 'Yes, because a higher acceptance rate always proves gaming.' }
  ]}
  explanation="Scores do not identify their production process. Separate participant responses from changes in who arrives, then examine genuine outcomes."
/>

Return to Original, cutoff 2. Compare two specified histories:

| History | Incoming population | Edits | Final-score law | Validity law | Accuracy |
|---|---|---|---|---|---|
| Strategic response | A/B/C/D each 1/4 | Best responses at k = 1 | 2, 2, 2, 3 in four equal-weight slots | 0, 0, 1, 1 | 2/4 |
| Changed population, passive protocol | C weight 3/4, D weight 1/4; A/B zero | None permitted | 2, 2, 2, 3 in four equal-weight slots | 1, 1, 1, 1 | 4/4 |

The second history keeps the **same type definitions** but changes their probabilities. Repeated C slots represent probability weight, not one person appearing repeatedly. These are alternative catalogues, not the original four individuals changing quality.

Exactly matched observables are **the final-score distribution and acceptance under the unchanged rule**. Both histories accept every submission. **G and accuracy are not matched**, and the organiser cannot recover them from the score alone.

Keep comparisons separate. Original passive→original strategic changes the opportunity to edit. Original passive→changed passive changes only population weights. Changing both and attributing the whole result to the rule would confound the explanations.

The changed passive history is not itself a Goodhart failure: there is no optimisation causing a loss of decision usefulness, and classification is correct. More generally, a predictive failure is not proof of deliberate gaming. [Manheim and Garrabrant](https://arxiv.org/pdf/1803.04585v4) distinguish selection, intervention and adversarial response; a disappointing number alone does not supply a mechanism.

### What to inspect

Retain the intake frame, scoring version, original/final score and edit logs, and independent validity checks where feasible. Outcomes test the objective; logs and assignment history distinguish explanations. Real checks may be costly or noisy. The oracle makes our reasoning inspectable, not those costs disappear.

## Transfer the audit when editing costs change

Work independently before opening the solution. Change only the edit cost to **k = 2**. Keep the original equally probable types, benefit 2.5, edits 0–4, score x + e and six cutoff choices.

Calculate responses under **Original, Raised and High**. Then check the other rules before choosing the accuracy maximum. A valid participant may rationally stay below the cutoff when crossing costs more than acceptance is worth.

<details>
<summary>Check the complete changed-cost comparison</summary>

| Rule | Cutoff | Edits A; B; C; D | Accepted | Correct | FP; FN | Mean cost |
|---|---|---|---|---|---|---|
| Open | 0 | 0; 0; 0; 0 | 4 | 2 | 2; 0 | 0 |
| Low | 1 | 1; 0; 0; 0 | 4 | 2 | 2; 0 | 1/2 |
| Original | 2 | 0; 1; 0; 0 | 3 | 3 | 1; 0 | 1/2 |
| Raised | 3 | 0; 0; 1; 0 | 2 | 4 | 0; 0 | 1/2 |
| High | 4 | 0; 0; 0; 1 | 1 | 3 | 0; 1 | 1/2 |
| Top | 5 | 0; 0; 0; 0 | 0 | 2 | 0; 2 | 0 |

Raised rejects A/B, lets C spend **2 × 1 = 2** for net utility **0.5**, and accepts D without editing. All classifications are correct. Total private cost over four slots is **2**; mean cost is **2/4 = 1/2**.

High requires two edits from C, costing **4 > 2.5**, so C stays and is incorrectly rejected. D spends 2 to cross. The old preferred rule now makes one error. Raised uniquely wins the whole menu.

</details>

Test the claim that **any rewarded target must lose its usefulness**. Change only the cost again to **k = 3**. Even one edit costs more than the benefit, so no participant edits under any rule:

| Rule | Cutoff | Edits A; B; C; D | Accepted | Correct | FP; FN | Mean cost |
|---|---|---|---|---|---|---|
| Open | 0 | 0; 0; 0; 0 | 4 | 2 | 2; 0 | 0 |
| Low | 1 | 0; 0; 0; 0 | 3 | 3 | 1; 0 | 0 |
| Original | 2 | 0; 0; 0; 0 | 2 | 4 | 0; 0 | 0 |
| Raised | 3 | 0; 0; 0; 0 | 1 | 3 | 0; 1 | 0 |
| High | 4 | 0; 0; 0; 0 | 0 | 2 | 0; 2 | 0 |
| Top | 5 | 0; 0; 0; 0 | 0 | 2 | 0; 2 | 0 |

Original retains **4/4 accuracy** despite public targeting and a positive benefit. This rejects inevitability, not the need for review. A different benefit, cheaper/different edits, population or objective can overturn it.

### When to reopen the choice

Recalculate when evidence changes the benefit, costs, actions, population or error weights. With those fixed, repeating “someone might game it” supplies no new response calculation. A restricted menu of cosmetic edits should not prevent investigating genuine improvement outside that menu.

### Sources and scope

[Hardt, Megiddo, Papadimitriou and Wootters](https://arxiv.org/pdf/1506.06980), arXiv version 2 from 2015, abstract and sections 1–1.2, supply the strategic-classification framework; the original section 1.1 equations were checked. [Manheim and Garrabrant](https://arxiv.org/pdf/1803.04585v4), version 4 from 2019, distinguish Goodhart mechanisms. The finite types, rules, costs and proofs are our own construction. No general classifier-learning theorem, empirical effectiveness or real screening recommendation is claimed.
