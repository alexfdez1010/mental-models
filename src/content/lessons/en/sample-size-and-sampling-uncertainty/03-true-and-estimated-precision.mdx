You can calculate an estimate from one sample. You can also calculate a number that estimates its precision. That second number is another statistic, with its own variation.

## The spread is fixed; its estimate can change

Return to the fixed eight-card population, four marked, with a uniform unordered sample of two. We already know the estimator's **true sampling variance** is $3/28$. “True” means calculated under the stipulated complete population and design; it is not a claim that an investigator normally knows that population.

For the observed pair, define the **sample variance**

$$s^2=\frac{(X_1-\hat P)^2+(X_2-\hat P)^2}{n-1},\qquad n=2.$$

This $n-1$ denominator belongs to a statistic computed inside a sample. It is different from averaging squared errors across all selections in lesson two. A homogeneous pair gives $s^2=0$. A mixed pair has mean 1/2, so its two squared departures sum to $1/4+1/4=1/2$; dividing by $n-1=1$ gives $s^2=1/2$.

For this simple random sample without replacement, use the variance estimator

$$\widehat V=\left(1-\frac nM\right)\frac{s^2}{n}=\frac38s^2.$$

Thus $\widehat V$ is zero for homogeneous pairs and $3/16$ for mixed pairs. It estimates the variance of $\hat P$, not the population proportion itself.

| $K$ | Probability | $s^2$ | Estimated variance $\widehat V$ | Estimated standard error $\sqrt{\widehat V}$ |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 3/14 | 0 | 0 | 0 |
| 1 | 4/7 | 1/2 | 3/16 | $\sqrt3/4\approx0.4330$ |
| 2 | 3/14 | 0 | 0 | 0 |

### What unbiased means here

Average the variance estimates over the pair catalogue:

$$E\widehat V=0\frac3{14}+\frac3{16}\frac47+0\frac3{14}=\frac3{28}.$$

So $\widehat V$ is unbiased for the true sampling variance **in this design**. Nevertheless, it reports zero with probability $3/14+3/14=3/7$. An estimator can be correct on average and poor for a particular realised sample. “Unbiased” is not a guarantee of a small realised error.

## Taking a square root changes the averaging

<MCQ client:visible
  className="not-prose"
  pretest={true}
  question={"An unbiased variance estimate is square-rooted. Which conclusion follows automatically?"}
  options={[{"text":"Its square root is also an unbiased standard-error estimate.","correct":false},{"text":"No unbiasedness conclusion follows from that operation alone.","correct":true},{"text":"Every positive estimate must now exceed the true standard error.","correct":false}]}
  explanation={"Taking a nonlinear function and taking an expectation need not commute. The finite catalogue lets us calculate the result directly."}
/>

The true standard error is $\sqrt{3/28}\approx0.3273$. The average estimated standard error is

$$E\sqrt{\widehat V}=\frac47\frac{\sqrt3}{4}=\frac{\sqrt3}{7}\approx0.2474.$$

These differ. You can verify the strict comparison without trusting rounded decimals: the square of the second quantity is $3/49$, smaller than $3/28$. We have demonstrated the failure of a particular inference in a complete finite model. We have not established a universal numerical correction for every estimated standard error.

| Quantity | Meaning | Value in this model |
| --- | --- | ---: |
| $\operatorname{SE}(\hat P)$ | True spread of the proportion estimator | $\sqrt{3/28}$ |
| $\widehat{\operatorname{SE}}=\sqrt{\widehat V}$ | Statistic reported from one pair | 0 or $\sqrt3/4$ |
| $E\widehat{\operatorname{SE}}$ | Average of that statistic over selections | $\sqrt3/7$ |

### When to use the distinction

Use it when a report presents a standard error as though it were an observed physical constant. Ask which estimator generated it and which collection assumptions justify that estimator. The simple random-sampling formula above is not automatically valid for copied rows, unequal selection probabilities or a changing population. Estimated precision can be unstable even when a target estimate is unbiased.

## Transfer without changing the collection law

You receive one realised pair with values 1 and 1. A colleague says: “The estimated standard error is zero, so our proportion estimate is exact.” Calculate the reported proportion, its actual error in this teaching population, and the probability that this variance estimator reports zero.

<details>
<summary>Audit the claim</summary>

The reported proportion is 1. The fixed target is 1/2, so the realised error is $1-1/2=1/2$. Both values are identical, giving $s^2=\widehat V=0$. Zero estimated standard error occurs for either kind of homogeneous pair, with probability $6/28+6/28=3/7$. It therefore cannot certify exactness. The known true standard error remains $\sqrt{3/28}$; it does not become the realised error of 1/2 either.

</details>
